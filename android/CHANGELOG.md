# Android v1.0

Первый публичный выпуск для Android.

* Активация сетевого модуля по Wi-Fi или через USB с компьютера.
* Отдельный экран USB с текущим статусом и командами для Windows,
  Linux и macOS.
* Локальный SOCKS5 для VPN/Tor-клиентов. Адрес по умолчанию — `127.0.0.1:1080`.
* Выбор/запуск/применение/остановка TCP/UDP/Discord стратегий.
* 484 TCP-стратегии (45 Golden и 439 Silver), QUIC Q1–Q5 и Discord/STUN D1–D8.
* Проверки TCP-стратегий для YouTube, Discord, LinkedIn, Facebook,
  X и Threads с метками (pass) и (unstable).
* Русский и английский интерфейсы, инструкции для VPN/Tor-клиентов,
  диагностика соединений и экспорт журналов.
* Светлая и тёмная темы с переключателем в «Логах и лицензиях».
* Один подписанный APK для Android 11+ с arm64-v8a, armeabi-v7a и x86\_64.

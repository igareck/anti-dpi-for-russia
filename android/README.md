# Igareck AntiDPI Android v1.0

Локальный SOCKS5 для Android 11 и новее. Приложение обрабатывает TCP и UDP через nfqws2, Lua, lwIP и TAP. Включены TCP-стратегии TCP1–TCP484, QUIC Q1–Q5 и Discord/STUN D1–D8.

Для установки скачайте **Igareck_AntiDPI_v1.0_Android_11+_Universal.apk** из [Releases](https://github.com/igareck/anti-dpi-for-russia/releases). Один APK содержит нативные библиотеки для arm64-v8a, armeabi-v7a и x86_64.

Откройте «Сетевой модуль» и выполните сопряжение по Wi-Fi. Для запуска с компьютера откройте «Активация через USB (если нет Wi-Fi, при наличии ПК)». После активации выберите стратегию и нажмите круглую кнопку «Запустить / применить». Адрес SOCKS5 по умолчанию — 127.0.0.1:1080.

У приложения есть русский и английский интерфейсы, шесть проверок сайтов и руководства для Karing, Exclave, v2rayNG, FlClash, Orbot и InviZible Pro. Метка (pass) означает два успешных замера, (unstable) — один из двух.

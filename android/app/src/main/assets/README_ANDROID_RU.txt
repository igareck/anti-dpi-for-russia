IGARECK ANTIDPI ANDROID · v1.0

Для начала откройте «Сетевой модуль» и выполните шаги
сопряжения по Wi-Fi. Для запуска с компьютера откройте
«Активация через USB (если нет Wi-Fi, при наличии ПК)». Требуется Android 11 или новее.

Когда появится «Сетевой модуль активен», выберите TCP-стратегию и
нажмите «Запустить / применить». Адрес локального SOCKS5 указан
в статусе работы. Порт по умолчанию 1080.

В «Инструкциях» есть готовый конфиг для Karing, настройки SOCKS5
и прокси-цепочки для Exclave и v2rayNG, скрипт и YAML для FlClash,
а также настройка Tor в Orbot и InviZible Pro. Для прямых голосовых звонков Discord включите в AntiDPI
«UDP через SOCKS» и «Discord/STUN».

«Стоп» останавливает текущие стратегии. Кнопка «Остановить сетевой
модуль» на экране активации завершает процесс модуля и приостанавливает
автовосстановление до ручного запуска.

«Проверка сайтов» проверяет TCP-стратегии для YouTube, Discord, LinkedIn,
Facebook, X и Threads. У каждого сайта отдельный диапазон, параллельность
от 1 до 5 и собственные результаты. Метка (pass) означает два успешных замера, 
метка (unstable) — один из двух. Доступ к ленте и вход в аккаунт
проверяйте в браузере. Проверка прерывается при повторном
нажатии кнопки или после 10 найденных стратегий. На время проверки
отключите VPN-клиент. Для VPN и Tor проверяйте узлы и мосты в их клиенте.

«Логи и лицензии» экспортирует диагностический ZIP на устройство
и показывает уведомления о лицензиях и их полные тексты. Здесь же
можно включить подробный журнал и запустить проверку трафика.
Для замера через клиент VPN/Tor выберите его в списке и укажите
порт его локального входа SOCKS5 (или Mixed с поддержкой SOCKS5).
Режим «Напрямую» использует сетевой маршрут приложения Igareck.
Для замера через SOCKS5 порт клиента должен быть доступен на 127.0.0.1.

Язык выбирается ссылкой внизу главного экрана. По умолчанию русский.

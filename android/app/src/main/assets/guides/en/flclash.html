Exclude Igareck AntiDPI from FlClash

1. Open the “Tools” tab. In “Settings”, tap “Access control”.

2. Open the ⋮ menu in the top right and tap “Enable”.
In the same menu, choose “Settings” → “Blacklist mode”.

3. Find Igareck AntiDPI, select it and tap the “Save” check mark.

FlClash now excludes Igareck AntiDPI.

Add the local SOCKS5 profile

1. Tap “Save YAML for FlClash” above.

2. Open FlClash → “Profiles” → + → “File” and select the saved YAML.
Use this profile for direct access through Igareck_AntiDPI_Local.

The default address is 127.0.0.1:1080. If you change the port in Igareck AntiDPI,
match it in the local YAML and the script below.

Access websites through a VPN

1. Open “Profiles” → + → “URL”, paste the direct YAML link and import the subscription.
If you have already added the subscription, go to the next step.

2. In “Profiles”, press and hold the subscription card.
Choose “Extension” → “Go to script settings”.
Tap + → “From scratch”, replace the template with the code below and save it as Igareck AntiDPI.

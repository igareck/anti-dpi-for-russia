Exclude Igareck AntiDPI from Orbot

1. Open “More” → “Choose apps”.

2. Select your browser and any other apps you want to route through Tor. Leave Igareck AntiDPI unchecked. Select at least one app. With an empty list, Orbot enables the VPN for the whole device. Return to the main screen.
Orbot now excludes Igareck AntiDPI.

Configure the outbound SOCKS5 proxy

1. Open “More” → “Orbot settings” → “Outbound network proxy (optional)”.

2. Set “Proxy type” to SOCKS5, “Proxy host” to 127.0.0.1 and “Proxy port” to @PORT@. Leave the username and password blank.

Access websites through Tor

1. On the main screen, tap “Configure connection” (“Configure transport”). Add your bridges through “Custom bridges” → “Next”.

2. Tap “Connect” and confirm Android’s VPN request if it appears. Wait for “Connected” and open the website in the browser you selected under “Choose apps”.
Orbot now uses the configured Igareck SOCKS5 proxy.

Access websites directly

Orbot cannot connect directly to the internet without Tor.
For direct access through Igareck AntiDPI, use InviZible Pro, Karing, Exclave, v2rayNG or FlClash.
Orbot uses the local SOCKS5 proxy only to connect to the Tor network.

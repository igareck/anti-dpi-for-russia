Exclude Igareck AntiDPI from Karing

1. Open “Settings” → “TUN” → “Proxied apps”.

2. Turn off “Whitelist mode”, find Igareck AntiDPI and select it.

Karing now excludes Igareck AntiDPI.


Choose either of the two options below.

Option 1

Add the local SOCKS5 chain profile

1. Copy the configuration above and open Karing.

2. On the main screen, tap “+ Add profile” → “Import from clipboard”.
Name the subscription Igareck_AntiDPI and disable scheduled updates.

3. Open “Settings” → “Routing” → “Chain proxy”. Enable “Front / chain proxy”, open “Server”, tap “+” and select Igareck_AntiDPI_Local.

Access websites through a VPN

1. Choose your VPN subscription.
2. Measure the latency of the configurations and connect to a working VPN node.
Karing will connect through the local Igareck SOCKS5 proxy.

Access websites directly

1. Instead of a VPN configuration, select the configuration named Igareck_AntiDPI_Local (the configuration above) and start it.

2. Open the website you need (Youtube/Discord/Linkedin and others) directly or use an app such as Discord App.

For Discord voice, enable UDP over SOCKS and Discord/STUN in AntiDPI.

Option 2

Add the local SOCKS5 profile

1. Copy the configuration above and open Karing.

2. On the main screen, tap “+ Add profile” → “Import from clipboard”.
Name the profile and disable scheduled updates.

Access websites through a VPN

If you are switching from option 1, turn off “Chain proxy” under “Routing”

1. In “Routing” → “Custom Auto Select”, create a group named “AntiDPI — entry”.
Then tap the arrow on the right and, from the subscriptions, add only the local SOCKS5 configuration Igareck_AntiDPI_Local to the group.

2. Create a second group named “VPN through AntiDPI”.
Then tap the arrow on the right and add the VPN subscriptions you need to the group.
For the “VPN through AntiDPI” group, open the “Front/chain proxy” icon (the icon with a circle) and assign the “AntiDPI — entry” group.

3. Return to the main screen. To the right of the power button (the shield icon), tap the right arrow to open the configuration selection menu.

4. Find and expand “Custom Auto Select” and select the “VPN through AntiDPI” group.

The “VPN through AntiDPI” group (containing the subscriptions previously selected for it) will work like a balancer using the LeastPing strategy, without the option to switch individual configurations manually. The “VPN through AntiDPI” group will connect to the selected VPN node through the local Igareck SOCKS5 proxy.

Access websites directly

1. Instead of the “VPN through AntiDPI” group, select either the “AntiDPI - entry” group
or the configuration named Igareck_AntiDPI_Local (the configuration above) and start it.

2. Open the website you need (Youtube/Discord/Linkedin and others) directly or use an app such as Discord App.

For Discord voice, enable UDP over SOCKS and Discord/STUN in AntiDPI.

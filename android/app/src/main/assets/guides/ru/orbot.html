Исключите Igareck AntiDPI из обработки Orbot

1. Откройте «Ещё» → «Выбор приложений».

2. Отметьте браузер и другие приложения, которые хотите направить через Tor. Igareck AntiDPI оставьте без отметки! Должно быть выбрано хотя бы одно приложение. При пустом списке Orbot включает VPN для всего устройства. Вернитесь на главный экран.
Теперь Igareck AntiDPI исключен из обработки Orbot.

Настройте исходящий SOCKS5

1. Откройте меню «Ещё» → «Настройки Orbot» → «Исходящий сетевой прокси (необязательно)».

2. В поле «Тип прокси» выберите SOCKS5. В поле «Хост прокси» укажите 127.0.0.1, в поле «Порт прокси» — @PORT@. Оставьте имя пользователя и пароль пустыми.

Доступ к сайтам через Tor

1. На главном экране нажмите «Настроить подключение» («Настроить транспорт»). Добавьте свои мосты через «Пользовательские мосты» → «Далее».

2. Нажмите «Подключить» и подтвердите запрос Android на создание VPN, если он появится. Дождитесь статуса «Подключено» и откройте сайт в браузере, который выбрали в Orbot в разделе «Выбор приложений».
Теперь Orbot использует настроенный SOCKS5 Igareck.

Доступ к сайтам напрямую

Использовать Orbot для доступа к сети напрямую без Tor не получится.
Для прямого доступа к сети через Igareck AntiDPI используйте InviZible Pro или Karing/Exclave/v2rayNG/FlClash.
Локальный SOCKS5 в Orbot служит для подключения только к сети Tor.

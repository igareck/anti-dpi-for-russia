Внесите Igareck AntiDPI в список исключений обработки Karing

1. Откройте «Настройки» → «TUN» → «Проксируемые приложения».

2. Отключите «Режим белого списка», найдите приложение Igareck AntiDPI и отметьте его.

Теперь Igareck AntiDPI исключен из обработки Karing.


Далее используйте любой из 2-х вариантов.

Вариант 1

Добавьте локальный цепочный SOCKS5-конфиг

1. Скопируйте конфиг выше и откройте Karing.

2. На главном экране нажмите «+ Добавить профиль» → «Импорт из буфера обмена».
Задайте имя подписки Igareck_AntiDPI и отключите интервал обновления.

3. Откройте «Настройки» → «Маршрутизация» → «Цепочный прокси». Включите «Фронтальный / цепной прокси», откройте «Сервер», нажмите «+» и выберите Igareck_AntiDPI_Local.

Доступ к сайтам через VPN

1. Выберите нужную VPN-подписку.
2. Измерьте задержку конфигураций и подключитесь к рабочему VPN-узлу.
Karing установит соединение через локальный SOCKS5 Igareck.

Доступ к сайтам напрямую

1. Вместо VPN-конфигурации выберите конфигурацию с именем Igareck_AntiDPI_Local (конфиг выше) и запустите ее.

2. Загружайте необходимый сайт (Youtube/Discord/Linkedin и другие) напрямую, либо пользуйтесь приложениями, такими как Discord App.

Для голоса Discord включите UDP через SOCKS и Discord/STUN в AntiDPI.

Вариант 2

Добавьте локальный SOCKS5-конфиг

1. Скопируйте конфиг выше и откройте Karing.

2. На главном экране нажмите «+ Добавить профиль» → «Импорт из буфера обмена».
Задайте имя профиля и отключите интервал обновления.

Доступ к сайтам через VPN

Если вы переходите с варианта 1, отключите «Цепочный прокси» в «Маршрутизации»

1. В «Маршрутизация» → «Пользовательский автоматический выбор» создайте группу с названием «AntiDPI — вход».
Далее нажмите на стрелку справа и там среди подписок добавьте в неё только один локальный SOCKS5-конфиг Igareck_AntiDPI_Local.

2. Создайте вторую группу с названием «VPN через AntiDPI».
Далее нажмите на стрелку справа и добавьте в группу нужные VPN-подписки.
Для группы «VPN через AntiDPI» откройте значок «Фронтальный/цепной прокси» (значок с кругом) и назначьте группу «AntiDPI — вход».

3. Вернитесь на главный экран. Справа от кнопки включения (значок щита) нажмите на стрелку вправо, чтобы перейти в меню выбора конфигураций.

4. Найдите и раскройте строку «Пользовательский автоматический выбор» и выберите группу «VPN через AntiDPI».

Группа «VPN через AntiDPI» (содержащая выбранные ранее в ней подписки) будет работать по принципу балансировщика со стратегией LeastPing, но без возможности ручной смены отдельного конфига. Группа «VPN через AntiDPI» будет соединяться с выбранным VPN-узлом через локальный SOCKS5 Igareck.

Доступ к сайтам напрямую

1. Вместо группы «VPN через AntiDPI» выберите или группу «AntiDPI - вход»,
или конфигурацию с именем Igareck_AntiDPI_Local (конфиг выше) и запустите ее.

2. Загружайте необходимый сайт (Youtube/Discord/Linkedin и другие) напрямую, либо пользуйтесь приложениями, такими как Discord App.

Для голоса Discord включите UDP через SOCKS и Discord/STUN в AntiDPI.

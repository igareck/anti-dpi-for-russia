Внесите Igareck AntiDPI в список исключений обработки FlClash

1. Откройте вкладку «Инструменты». В разделе «Настройки» нажмите «Контроль доступа».

2. Откройте меню с тремя точками ⋮ справа вверху. Нажмите «Включить».
Затем в том же меню выберите «Настройки» → «Режим чёрного списка».

3. Найдите Igareck AntiDPI, отметьте его и нажмите галочку «Сохранить».

Теперь Igareck AntiDPI исключен из обработки FlClash.

Добавьте локальный профиль SOCKS5

1. Кнопкой выше нажмите «Сохранить YAML для FlClash».

2. Откройте FlClash → «Профили» → + → «Файл» и выберите сохранённый YAML.
Этот профиль понадобится для прямого доступа через Igareck_AntiDPI_Local.

По умолчанию используется 127.0.0.1:1080. Если вы изменили порт в Igareck AntiDPI,
проверьте, что он совпадает с портом в локальном YAML и в скрипте ниже.

Доступ к сайтам через VPN

1. Откройте «Профили» → + → «Ссылка», вставьте прямую ссылку на YAML и импортируйте подписку.
Если подписка уже добавлена, переходите к следующему шагу.

2. В разделе «Профили» удерживайте нажатием карточку подписки.
Выберите «Расширение» → «Перейти к настройке скрипта».
Нажмите + → «С нуля», замените шаблон кодом ниже и сохраните скрипт под именем Igareck AntiDPI.

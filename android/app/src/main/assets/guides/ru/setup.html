1. Включите режим разработчика Android.

2. Активируйте сетевой модуль, используя любую доступную Wi-Fi точку, с интернетом или без (неважно), важен сам факт подключения к Wi-Fi. Альтернативно можно использовать USB-подключение к ПК.

3. Выберите стратегию и нажмите «Запустить / Применить» (круглая кнопка).

4. Затем настройте VPN-клиент согласно настройкам ниже.

Локальный SOCKS5 · 127.0.0.1:@PORT@. Если измените порт AntiDPI, обновите его в профиле клиента.

В настройках VPN-клиента исключите Igareck AntiDPI из списка приложений, обрабатываемых через VPN.

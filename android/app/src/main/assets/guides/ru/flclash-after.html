3. Вернитесь на экран «Расширение» этой подписки.
В поле «Скрипт расширения» выберите Igareck AntiDPI.
Если появилась кнопка «Применить сейчас», нажмите её.

4. В «Профили» выберите карточку подписки. На «Панели» в разделе «Режим исходящего трафика» выберите «Правило» и нажмите «Старт».

5. Откройте вкладку «Прокси». В группе Igareck Manual (Ручное Подключение) выберите Igareck Auto Select (Автоподключение) для автоматического выбора.
Для ручного выбора запустите «Тест задержки» и нажмите на рабочий VPN-узел в той же группе.

Доступ к сайтам напрямую

1. Откройте «Профили» и выберите карточку локального YAML, импортированного через «Сохранить YAML для FlClash» выше.

2. На «Панели» в разделе «Режим исходящего трафика» выберите «Правило».
Если FlClash остановлен, нажмите «Старт».

3. Откройте нужный сайт или приложение.
Igareck_AntiDPI_Local направит трафик, принятый FlClash, через локальный SOCKS5 Igareck напрямую к сайту.

Для голоса Discord включите UDP через SOCKS и Discord/STUN в AntiDPI.

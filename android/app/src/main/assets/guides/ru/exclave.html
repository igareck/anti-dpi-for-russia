Внесите Igareck AntiDPI в список исключений обработки Exclave

1. Откройте боковое меню ☰ → «Настройки».
Найдите раздел «Настройки маршрута» и нажмите на «Режим VPN для приложений».

2. Вверху выберите «Обход», найдите приложение Igareck AntiDPI и отметьте его.
Теперь Igareck AntiDPI исключён из VPN-туннеля Exclave.

Добавьте локальный профиль SOCKS5

Откройте боковое меню ☰ → «Конфигурация».

На экране «Конфигурация» нажмите → «Ручные настройки» → «Другие» → «SOCKS».
Укажите имя Igareck_AntiDPI_Local, сервер 127.0.0.1, порт @PORT@ и версию SOCKS5.
Оставьте имя пользователя и пароль пустыми и нажмите галочку «Применить».

Доступ к сайтам через VPN

1. Откройте боковое меню ☰ → «Группы».

На экране «Группы» нажмите на карандаш рядом с нужной VPN-подпиской.
Откройте «Начальный прокси» → «Выбрать профиль…» и выберите Igareck_AntiDPI_Local.
«Конечный прокси» оставьте в состоянии «Отключено».
Сохраните настройки группы, нажав на галочку «Применить».

2. Вернитесь на вкладку с подпиской/балансировщиком (☰ → «Конфигурация»).

3. Если заранее был настроен балансировщик и необходимо работать через него:

На экране «Конфигурация» откройте локальную группу с балансировщиком.
Обычно это «Без группы».
Нажмите на карандаш рядом с балансировщиком, чтобы перейти в его настройки.
Там активируйте «Использовать начальный прокси группы».
Сохраните настройки, нажав на галочку «Применить».
Далее выберите балансировщик и запустите подключение.

4. Если нужно работать вручную со всеми конфигурациями подписки:

Нажмите на название подписки сверху.
Откройте меню ⋮ → «Тест подключения» → «URL test», дождитесь окончания тестирования.
Выберите рабочий VPN-узел и запустите подключение.
Exclave установит соединение с ним через локальный SOCKS5 Igareck.

Доступ к сайтам напрямую

1. Откройте боковое меню ☰ → «Конфигурация».

На экране «Конфигурация» откройте локальную группу, в которой сохранён SOCKS5-профиль.
Обычно это «Без группы».
Выберите сам профиль Igareck_AntiDPI_Local и запустите подключение.

2. Загружайте необходимый сайт (Youtube/Discord/Linkedin и другие) напрямую, либо пользуйтесь приложениями такими как Discord App.
Exclave передаст его трафик локальному SOCKS5 Igareck для прямого соединения с сайтом.

Для голоса Discord включите UDP через SOCKS и Discord/STUN в AntiDPI.

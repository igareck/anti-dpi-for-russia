Исключите Igareck AntiDPI из обработки InviZible Pro.

1. На главном экране откройте меню ⋮ и выберите VPN Mode.

2. Откройте боковое меню ☰ → «Быстрые настройки».
Если «Весь интернет через Tor» включен: в разделе «Настройки Tor» нажмите «Исключить приложения».
Если «Весь интернет через Tor» выключен: в разделе «Настройки Tor» нажмите «Выбрать приложения».

3. Найдите Igareck AntiDPI и нажмите «Исключить полностью». Вернитесь назад, чтобы сохранить выбор.
Теперь Igareck AntiDPI исключен из обработки InviZible Pro.

Настройте исходящий SOCKS5

1. Откройте ☰ → «Общие настройки». В разделе «Прокси» нажмите «Использовать Socks5 прокси».

2. Укажите Прокси сервер 127.0.0.1 и Прокси порт @PORT@. Поля «Пользователь» и «Пароль» оставьте пустыми.

3. На этом же экране нажмите «Исключить приложения», отметьте Igareck AntiDPI и вернитесь назад.

4. Отметьте только «Использовать прокси для Tor», нажмите «Сохранить и активировать» и вернитесь на главный экран.

Доступ к сайтам через Tor

1. Чтобы подключить мост, откройте ☰ → «Быстрые настройки». В разделе «Настройки Tor» нажмите «Мосты» → «Добавить мосты», вставьте строки с мостами из подписки GitHub и нажмите OK.

2. На экране «Мосты» выберите «Использовать свой список мостов». В выпадающем списке рядом выберите obfs4, webtunnel или vanilla. Включите переключатель напротив каждого моста, который хотите использовать, и вернитесь назад.

3. Если вы включили «Весь интернет через Tor», то выбирать приложения не нужно.
Если вы выключили «Весь интернет через Tor», откройте «Выбрать приложения» и отметьте «Использовать с Tor» у нужного браузера/приложения.

4. На главном экране отметьте «Скрыть IP с помощью TOR» и «Защититься с помощью DNSCRYPT», затем нажмите START. Подтвердите запрос Android на создание VPN, если он появится. Дождитесь статуса «Tor работает» и откройте сайт.
InviZible Pro подключится к Tor через локальный SOCKS5 Igareck.

Доступ к сайтам напрямую

1. Откройте ☰ → «Общие настройки» → «Использовать Socks5 прокси». Включите «Использовать прокси для приложений, которые работают без Tor» и нажмите «Сохранить и активировать».

2. На главном экране нажмите STOP, если модули уже запущены. Снимите отметку «Скрыть IP с помощью TOR», отметьте «Защититься с помощью DNSCRYPT» и нажмите START.
DNSCrypt позволит сохранить VPN InviZible Pro активным при остановленном Tor.

3. Загружайте необходимый сайт (Youtube/Discord/Linkedin и другие) напрямую, либо пользуйтесь приложениями, такими как Discord App.
InviZible Pro направит TCP-соединение через локальный SOCKS5 Igareck.

Для звонков в Discord клиент InviZible Pro непригоден.
Tor и описанный прямой режим InviZible Pro проксируют только TCP.
Для звонков используйте локальный SOCKS5-профиль в Karing и включите «UDP через SOCKS» и «Discord/STUN» в Igareck AntiDPI.
